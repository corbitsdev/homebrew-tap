# Homebrew Tap for Corbits Code

Install [Corbits Code](https://github.com/corbitsdev/corbits-code):

```bash
brew tap corbitsdev/tap
brew install corbits-code
```

Upgrade:

```bash
brew update && brew upgrade corbits-code
```

The CLI binary on your PATH is `corbits`.

Formula is regenerated by `scripts/release.sh` in `corbitsdev/corbits-code` on every tagged release.
